# Домашнее задание "Отказоустойчивость в облаке"

## Задание 1
1. Terraform Playbook:
   * **main.tf** - основной файл архитектуры: создает сеть, подсеть, 2 идентичные ВМ, таргет-группу и балансировщик.
   * **meta.txt** - cloud-init конфигурация, которая создаёт пользователя, добавляет SSH-ключ и автоматически устанавливает Nginx,
   * **outputs.tf** - выводит публичный IP-адрес балансировщика в консоль по завершении развертывания,
   * **providers.tf** - инициализирует провайдер Yandex Cloud и связывает его с переменными для авторизации в облачной инфраструктуре,
   * **variables.tf** - служит для объявления входных переменных.
Все файлы представлены в репозитории.
